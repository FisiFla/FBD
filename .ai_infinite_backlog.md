## Risks / Known Gaps

- macOS 27 beta: SLSDisplaySetPresetData write-protected (XDR native upscaling → software fallback), IOMobileFramebufferOpen entitlement-gated, VirtualDisplay.framework absent (SidecarCore path), True Tone degraded. Tracked in docs/PRIVATE_APIS.md; re-check per beta.
- CI runs Intel (macos-15): DDC mock tests run everywhere now, but no arm64 CI coverage without paid xlarge runner.
- HTTP server: hand-rolled HTTP/1.1 — keep-alive/chunked unsupported by design (Connection: close); clients must handle it (fbdcli does).
- Sparkle: feed URL empty → updates inert until a release exists (by design).
- Case-insensitive filesystem footgun: target directories must not be case-variants (FBDCLIParser precedent).
