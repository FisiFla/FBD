# UI Revamp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace FBD's titled, everything-expanded panel with a borderless Control Center–style popover (page stack, quick toggles, presets, Liquid Glass on macOS 26+) and move Settings to its own window.

**Architecture:** A `@MainActor PanelModel` owns panel state and the navigation route; small page views render it; a shared design system (`FBDListRow`, `FBDToggleTile`, `FBDPageHeader`, `FBDGlass`) carries the visual language. FBDCore controllers are reused unchanged. Foundation (Tasks 1–4) is sequential; Tasks 5–8 touch disjoint files and run in parallel; Task 9 integrates.

**Tech Stack:** Swift 5.9+ (built with Xcode 26+/Swift 6.2 toolchain), SwiftUI + AppKit, SwiftPM, XCTest. Deployment target macOS 13.2.

**Spec:** `docs/superpowers/specs/2026-10-16-ui-revamp-design.md`

## Global Constraints

- Deployment target stays `.macOS(.v13)`; every macOS 26 API is behind `#if compiler(>=6.2)` **and** `if #available(macOS 26, *)`, with a material fallback.
- No view outside `Sources/FBD/DesignSystem/FBDGlass.swift` calls `glassEffect`, `GlassEffectContainer`, `glassEffectID` or `.buttonStyle(.glass)` directly.
- Popover width 340 pt; height = content, capped at 85% of the screen's `visibleFrame.height`.
- Type scale: display name 13 pt semibold; secondary 11 pt `.secondary`; section header 11 pt semibold `.secondary`. No large titles in the popover.
- `FBDListRow`: 26 pt icon chip, 32 pt row height. `FBDToggleTile`: 44 pt circle. `FDBSlider`: 6 pt track, 20 pt pill thumb.
- System appearance + system accent; red only for destructive actions; no per-kind tints on the front page.
- Every user-facing string goes through `LocalizedStringKey` / `String(localized:)` and has keys in `en`, `zh-Hans`, `zh-Hant` `Localizable.strings`; no raw identifiers (`refreshRate`, `hdrMode`, `mainStatus`, …) in the UI.
- Destructive actions keep their confirmations (`FBDConfirmation`).
- FBDCore behaviour, `fbdcli` and the HTTP API are out of scope — do not modify `Sources/FBDCore` except where a task says so.
- Build/test commands: `swift build`, `swift test --disable-sandbox`, `make app`. All must pass at every commit.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **No external display / only a virtual display** — home page must still render (display section shows what exists; volume rows absent; toggles/presets/nav rows present). Test in Task 3 (`testNoDDCDisplayHidesVolume`, `testEmptyDisplayListRendersHomeRoute`).
2. **Display disappears while its detail page is open** (unplug, sleep, disconnect) — route must fall back to `.home`, not crash or show a stale page. Test in Task 3 (`testRouteFallsBackWhenDisplayVanishes`).
3. **Many displays / many presets on a small screen** — popover height must cap at 85% and scroll, never extend off-screen. Test in Task 4 (`testPanelHeightIsCappedToScreen`).
4. **Quick toggle the system can't drive** (True Tone unavailable, Dark Mode SPI missing) — tile disabled with reason, tapping does nothing. Test in Task 3 (`testUnavailableToggleIsDisabled`).
5. **Settings requested while popover is closed** (`.fbdOpenSettings` from URL scheme / HTTP / menu) — must open the Settings window, not the popover. Test in Task 4 (`testOpenSettingsNotificationShowsWindow` via the window controller's `isVisible`).

```swift
import SwiftUI

/// The one place FBD touches Liquid Glass. macOS 26+ and a Swift 6.2 toolchain get the
/// system glass; anything else gets the material/translucent fallback, so no other file
/// needs an availability check.
enum FBDGlass {
    /// `FBD_DISABLE_GLASS=1` forces the fallback so the macOS 13–25 look can be checked on 26+.
    static var isAvailable: Bool {
        if ProcessInfo.processInfo.environment["FBD_DISABLE_GLASS"] == "1" { return false }
        #if compiler(>=6.2)
        if #available(macOS 26, *) { return true }
        #endif
        return false
    }
}

extension View {
    /// Glass in `shape` (controls layer only — never on content rows).
    @ViewBuilder
    func fbdGlass<S: Shape>(in shape: S, tint: Color? = nil, interactive: Bool = false) -> some View {
        #if compiler(>=6.2)
        if #available(macOS 26, *), FBDGlass.isAvailable {
            var glass = Glass.regular
            if let tint { glass = glass.tint(tint) }
            if interactive { glass = glass.interactive() }
            self.glassEffect(glass, in: shape)
        } else {
            fallbackGlass(in: shape, tint: tint)
        }
        #else
        fallbackGlass(in: shape, tint: tint)
        #endif
    }

    @ViewBuilder
    func fbdGlassButton() -> some View {
        #if compiler(>=6.2)
        if #available(macOS 26, *), FBDGlass.isAvailable {
            self.buttonStyle(.glass)
        } else {
            self.buttonStyle(.bordered)
        }
        #else
        self.buttonStyle(.bordered)
        #endif
    }

    @ViewBuilder
    func fbdGlassID(_ id: String, in namespace: Namespace.ID) -> some View {
        #if compiler(>=6.2)
        if #available(macOS 26, *), FBDGlass.isAvailable {
            self.glassEffectID(id, in: namespace)
        } else {
            self
        }
        #else
        self
        #endif
    }

    private func fallbackGlass<S: Shape>(in shape: S, tint: Color?) -> some View {
        background(
            ZStack {
                shape.fill(.regularMaterial)
                if let tint { shape.fill(tint.opacity(0.85)) }
            }
        )
    }
}

/// Groups glass elements so they blend/morph together on macOS 26+; a plain stack before.
struct FBDGlassContainer<Content: View>: View {
    let spacing: CGFloat
    @ViewBuilder let content: () -> Content

    var body: some View {
        #if compiler(>=6.2)
        if #available(macOS 26, *), FBDGlass.isAvailable {
            GlassEffectContainer(spacing: spacing) { content() }
        } else {
            content()
        }
        #else
        content()
        #endif
    }
}
```

import SwiftUI

/// The popover's one row: icon chip · title · optional value · optional chevron/checkmark.
/// Whole row is the hit target; hover highlight like a native menu.
struct FBDListRow: View {
    let symbol: String
    let title: LocalizedStringKey
    var value: String? = nil
    var showsChevron = false
    var isChecked = false
    var role: ButtonRole? = nil
    let action: () -> Void

    @State private var isHovering = false

    var body: some View {
        Button(role: role, action: action) {
            HStack(spacing: FBDTheme.spacingL) {
                Image(systemName: symbol)
                    .font(.system(size: 12, weight: .medium))
                    .foregroundStyle(role == .destructive ? Color.red : Color.primary)
                    .frame(width: FBDTheme.chipSize, height: FBDTheme.chipSize)
                    .background(Circle().fill(Color.primary.opacity(0.08)))
                Text(title)
                    .font(.system(size: 13))
                    .foregroundStyle(role == .destructive ? Color.red : Color.primary)
                Spacer(minLength: FBDTheme.spacingM)
                if let value {
                    Text(value).font(FBDTheme.Font.secondary).foregroundStyle(.secondary)
                }
                if isChecked {
                    Image(systemName: "checkmark").font(.system(size: 11, weight: .semibold))
                        .foregroundStyle(Color.accentColor)
                }
                if showsChevron {
                    Image(systemName: "chevron.right").font(.system(size: 11, weight: .semibold))
                        .foregroundStyle(.tertiary)
                }
            }
            .padding(.horizontal, FBDTheme.spacingM)
            .frame(height: FBDTheme.rowHeight)
            .contentShape(Rectangle())
            .background(
                RoundedRectangle(cornerRadius: FBDTheme.radiusTile)
                    .fill(Color.primary.opacity(isHovering ? 0.07 : 0))
            )
        }
        .buttonStyle(.plain)
        .onHover { isHovering = $0 }
        .accessibilityAddTraits(isChecked ? .isSelected : [])
    }
}

import SwiftUI

/// Control Center–style round toggle: glass circle, label, On/Off.
struct FBDToggleTile: View {
    let symbol: String
    let title: LocalizedStringKey
    let isOn: Bool
    var isEnabled = true
    var disabledReason: LocalizedStringKey? = nil
    let action: () -> Void

    static func stateText(isOn: Bool, isEnabled: Bool) -> LocalizedStringKey {
        guard isEnabled else { return "Unavailable" }
        return isOn ? "On" : "Off"
    }

    var body: some View {
        Button(action: action) {
            VStack(spacing: FBDTheme.spacingXS) {
                Image(systemName: symbol)
                    .font(.system(size: 17, weight: .medium))
                    .foregroundStyle(isOn ? Color.white : Color.primary)
                    .frame(width: FBDTheme.tileSize, height: FBDTheme.tileSize)
                    .fbdGlass(in: Circle(), tint: isOn ? Color.accentColor : nil, interactive: isEnabled)
                Text(title).font(.system(size: 11, weight: .semibold)).lineLimit(1)
                Text(Self.stateText(isOn: isOn, isEnabled: isEnabled))
                    .font(FBDTheme.Font.secondary).foregroundStyle(.secondary)
            }
            .frame(maxWidth: .infinity)
            .opacity(isEnabled ? 1 : 0.45)
        }
        .buttonStyle(.plain)
        .disabled(!isEnabled)
        .help(disabledReason.map { Text($0) } ?? Text(title))
        .accessibilityElement(children: .combine)
        .accessibilityAddTraits(.isToggle)
        .accessibilityValue(Text(Self.stateText(isOn: isOn, isEnabled: isEnabled)))
    }
}

/// Popover state: what's shown, where we are, and the actions pages call.
@MainActor
final class PanelModel: ObservableObject {
    @Published private(set) var route: PanelRoute = .home
    @Published private(set) var displays: [Display]
    @Published private(set) var toggles: [QuickToggle] = []
    @Published private(set) var virtualScreenCount = 0
    @Published private(set) var groupCount = 0
    /// Whether each display answered a DDC volume read. Absent = not probed yet = hidden.
    @Published var volumeAvailability: [CGDirectDisplayID: Bool] = [:]

    private let toggleBackend: QuickToggleBackend
    private let counts: () -> (virtualScreens: Int, groups: Int)
    private var observers: [NSObjectProtocol] = []

    init(
        displays: [Display],
        toggleBackend: QuickToggleBackend,
        counts: @escaping () -> (virtualScreens: Int, groups: Int)
    ) {
        self.displays = displays
        self.toggleBackend = toggleBackend
        self.counts = counts
        refreshToggles()
        refreshCounts()
    }

    static func live() -> PanelModel {
        let groups = DisplayGroupsController()
        let model = PanelModel(
            displays: DisplayController.shared.displays,
            toggleBackend: SystemQuickToggleBackend(),
            counts: { (VirtualScreenController.shared.screens.count, groups.groups.count) }
        )
        model.observeSystem()
        return model
    }

    // MARK: Navigation

    func open(_ route: PanelRoute) {
        if let id = route.displayID, display(id: id) == nil { self.route = .home; return }
        self.route = route
    }

    func back() {
        if let parent = route.parent { route = parent }
    }

    func display(id: CGDirectDisplayID) -> Display? {
        displays.first { $0.id == id }
    }

    func reloadDisplays(_ displays: [Display]) {
        self.displays = displays
        if let id = route.displayID, display(id: id) == nil { route = .home }
        refreshCounts()
    }

    // MARK: Toggles

    func toggle(_ kind: QuickToggle.Kind) {
        guard let current = toggles.first(where: { $0.id == kind }), current.isAvailable else { return }
        _ = toggleBackend.set(kind, on: !current.isOn)
        refreshToggles()
    }

    func refreshToggles() {
        toggles = QuickToggle.Kind.allCases.map { kind in
            let s = toggleBackend.state(kind)
            return QuickToggle(id: kind, isOn: s.isOn, isAvailable: s.isAvailable)
        }
    }

    func refreshCounts() {
        let c = counts()
        virtualScreenCount = c.virtualScreens
        groupCount = c.groups
    }

    // MARK: Volume

    func showsVolume(forID id: CGDirectDisplayID) -> Bool { volumeAvailability[id] == true }
    func showsVolume(for display: Display) -> Bool { showsVolume(forID: display.id) }

    /// Probes DDC volume off the main actor (DDC reads block), once per display.
    func probeVolume(for display: Display) {
        guard volumeAvailability[display.id] == nil, display.ddcAvailable else {
            if !display.ddcAvailable { volumeAvailability[display.id] = false }
            return
        }
        Task.detached { [weak self] in
            let answered = DisplayController.shared.readVolume(for: display) != nil
            await MainActor.run { self?.volumeAvailability[display.id] = answered }
        }
    }

    // MARK: Presets

    func presets(for display: Display) -> [DisplayPreset] {
        DisplayPresets.presets(for: display.identityKey)
    }

    func apply(_ preset: DisplayPreset, to display: Display) {
        let outcome = DisplayPresetApplier.apply(
            preset, to: display, resolution: ResolutionController(), controller: DisplayController.shared
        )
        if outcome.applied.isEmpty && !outcome.requested.isEmpty {
            FBDNotice.shared.report(String(localized: "Nothing in '\(preset.name)' applies to this display."))
        } else {
            FBDNotice.shared.report(String(localized: "Applied '\(preset.name)'."))
        }
    }

    // MARK: System observation

    private func observeSystem() {
        let center = NotificationCenter.default
        for name in [Notification.Name.fbdDisplaysChanged, .fbdDisplayUpdated] {
            observers.append(center.addObserver(forName: name, object: nil, queue: .main) { [weak self] _ in
                MainActor.assumeIsolated { self?.reloadDisplays(DisplayController.shared.displays) }
            })
        }
        observers.append(center.addObserver(forName: .fbdVirtualScreensChanged, object: nil, queue: .main) { [weak self] _ in
            MainActor.assumeIsolated { self?.refreshCounts() }
        })
        observers.append(DistributedNotificationCenter.default().addObserver(
            forName: DarkModeController.themeChangedNotification, object: nil, queue: .main
        ) { [weak self] _ in
            MainActor.assumeIsolated { self?.refreshToggles() }
        })
    }
}
